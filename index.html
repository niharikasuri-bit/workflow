Guide to make a process flow

Six steps from an empty canvas to downloadable code.

  1. Add a start state Click Start state in the left panel, or drag it onto the canvas. A process flow has one start state, and its form is included.
  2. Add the other states Add an intermediate state for each step, and an end state for every way the process flow can finish. Drag states on the canvas to arrange them.
  3. Connect states with actions Drag from the + on a state to the next state, or click the + and then the next state.
  4. Set up each state Select a state to set its SLA, notifications, documents, payments and auto escalation.
  5. Set up each action Select an action’s label on the canvas to choose its roles, attach a checklist and turn on its settings.
  6. Check and download Fix anything listed under issues, then use View Configuration to copy or download the code.
